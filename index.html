Puzzle. Three ferries leave Limassol at 06:00. They return every 36, 48, and 60 minutes. When are all three next in port together?

              
    
                
  1. 1Reframe: the answer is the least common multiple of 36, 48, and 60 minutes after 06:00.
    2. 
                
  2. 2Factor: 36 = 2²·3², 48 = 2⁴·3, 60 = 2²·3·5.
    3. 
                
  3. 3Take the highest power of each prime: 2⁴ · 3² · 5 = 720.
    4. 
                
  4. 4720 minutes is exactly 12 hours. Sanity check: 720 ÷ 36 = 20, ÷ 48 = 15, ÷ 60 = 12 — all whole.
    5. 
              

              
All three are in port together at 18:00.

06 — Under the hood

            
No frameworks. No API keys. Just the web.

          

          
This page is itself an artifact of the model's craft: hand-written HTML, CSS, and vanilla JavaScript, deployable anywhere a static file can live.

        


        

          

            01
            
Zero dependencies

            
Canvas particle field, syntax highlighting, drag and drop, charts and the command palette are all written from scratch. The only network requests are web fonts.

          

          

            02
            
Honest simulations

            
The demos replay scripted model output so they work offline and on GitHub Pages. Swap the fixtures for a real endpoint and the UI stays identical.

          

          

            03
            
Accessible by default

            
Semantic landmarks, keyboard-operable controls, live regions for streamed text, a table fallback for the chart, and full prefers-reduced-motion support.
